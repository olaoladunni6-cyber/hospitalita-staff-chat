# Hospitalita Staff Chat

Private internal messaging portal for Hospitalita Ltd staff.

## Features
- Staff-only login
- Private 1-on-1 chats for official matters
- Message history stored locally (browser)
- File & image attachments
- Professional, mobile-friendly interface

## Live Demo
https://azure-hyssop-vmanm.ship.place/

## Demo Login
- Email: any staff email (e.g. dunni@hospitalita.com)
- Password: `HospitalitaStaff`

## Note
This is a frontend prototype using browser localStorage. Messages are stored on the device. For production multi-user shared chat with central server storage, a backend (e.g. Firebase, Supabase, or custom Node/Python) is required.
